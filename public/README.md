# 公开静态资源

后续存放低面数角色、球馆模型、纹理等资源。当前未加入美术资源。

- 先用简单代理角色验证触控；美术完善不应阻塞业务闭环。
- 基础几何和材质尽量复用，姓名通过清晰二维标签显示。
- avatarKey 是外观选择键，不是 playerId 的替代品。
- 角色身份绑定在运行时构建的实体上，不能依赖模型节点名字猜测选手。
- 同一角色的更换外观不能改变历史阵容。
- 资源路径应支持稳定缓存与版本更新，发布时随 Sites 构建产物打包。
- 此目录内容会对站点访问者开放，不放数据库、真实赛果备份或密钥。

预算与验证见 [架构](../docs/architecture/overview.md)、[手机验收](../docs/delivery/validation-and-release.md)。
