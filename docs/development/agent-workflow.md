# 新 thread、验证与安全并行

这是本项目的操作说明；规则和数据定义仍从 [需求](../product/requirements.md)、[架构](../architecture/overview.md) 与 [数据契约](../architecture/data-and-sync.md) 获取。命令、依赖和测试选择以 `package.json`、锁文件和配置为准。

## 接手

1. 查看当前工作目录、HEAD、工作区和暂存区；记录已有改动及其所属任务。完成条件：本任务要写的文件、要运行的进程、要使用的数据目录与其他任务明确分开。
2. 读 [README](../../README.md) 的当前交付状态和 [实施计划](../delivery/implementation-plan.md)；按根 AGENTS 的任务入口取资料。完成条件：确认自己是在现有应用上续做，并能指出本次对应的阶段与验收项。
3. 从 Git diff 和实际文件判断当前实现，查看已有测试和脚本后再新增检查。测试数量从当前 runner 获取；历史验收中的数量只描述当时的版本。

旧 thread 用于追溯，不是当前工作清单。优先读取指定 thread 的用户确认和最终结论；遇到具体失败再展开对应命令。历史工具输出逐项限长仍可能非常大，先在工具编排层筛选，不把整段历史注入上下文。

## 与开发任务并行

- 使用自己的 worktree；它有独立工作区、index、依赖、`dist/`、`.wrangler/` 和本机测试活动。已有运行服务和数据库留给原任务。
- 写入前确定文件白名单。共享目录即使暂时干净，也不代表整个仓库属于当前任务。
- 提交前核对 diff 和暂存文件，只暂存本任务路径。在被迫共享 index 时，保留他人已暂存内容，使用显式路径的 `git commit --only -- <本任务路径>`；不要通过全量暂存或重置 index 来排除他人内容。
- 集成前重读目标 checkout 的 HEAD、dirty 与 staged 状态，并核对本提交路径没有交集。优先快进；若目标 HEAD 已推进，只在私有 worktree 中调整本任务尚未共享的提交。发生同文件冲突时保持原 checkout 不变，在隔离区处理。
- 完成时报告本次提交及仍由其他任务持有的改动；把“本任务干净”和“整个主工作区干净”区分开。

上述流程不授权替其他 thread 提交、停止其服务或改变其数据库。

## 选择验证

[CI 工作流](../../.github/workflows/ci.yml) 串接现有安装、lint、类型、测试、构建、本地迁移和 HTTP 检查；它只在独立 runner 做本地验证，不发布 Site。仓库尚未配置远端时，提交工作流不等于远端 CI 已运行。

- 纯文档：核对指针目标、相互引用和事实来源；不要为此占用另一个任务的端口或重装其依赖。
- 业务、存储或同步：在相应 Module Interface 运行已有行为检查；真实 D1 语义用现有 records 集成检查。
- HTTP、身份、请求体或框架装配：使用现有 `verify:local` 与 `verify:production`。首次演练采用独立 eventId，保留脚本自动创建的测试活动隔离。
- 场景和界面：做与改动相关的浏览器操作及截图；浏览器缩窄视口不能代替实际 iPhone 的触控、键盘或后台恢复。
- 构建相关改动：功能与界面稳定后做一次最终构建；出现新失败或新的相关修改再重跑。

首次安装、构建、迁移和初始化的顺序见 [README 本地运行](../../README.md#本地运行)。迁移器读取 `dist/server/wrangler.json`，所以干净 checkout 需要先构建，不能跳过该前置条件。

## 进程与环境

先确认监听端口、进程归属及 checkout；复用服务只做已获授权的操作。需要独立预览时选择自己的端口，并通过脚本开头的 `SOPHIA_LOCAL_URL` 或 `SOPHIA_PRODUCTION_URL` 指向它。日志放本任务的 `outputs/` 或 `.sites-runtime/`，先建目录再重定向。

Windows 上，运行中的预览会锁定原生模块或构建产物。重装自己 worktree 的依赖前停止自己的预览；重建前停止自己占用 `dist/` 的生产预览。遇到 EBUSY／EPERM 先定位持有者，不清理或停止其他任务来解除锁定。已有受限环境配置办法见 README；不把它写成全局机器设置。

PowerShell 读取包含 `[eventId]` 的路由路径时使用 `-LiteralPath`，按字面文件名定位。

HTTP 早返回曾留下未消费请求体，导致随后 SSR 流挂起；对应回归已在 `scripts/verify-production.mjs` 中。此路径的改动用该现有检查验证，不靠“接口返回了错误码”单独判定完成。

手机使用它实际访问的 origin 验收。电脑 localhost 的浏览器能力、开发身份和访问成功，只证明该环境；手机网络访问、权限和实际 Safari 行为分别记录。局域网接入正在推进时，以当前实现、用户授权范围和该任务的操作说明为准，不在另一任务中代为开放网络。
