# 连续三场地与场内记分牌

2026-10-29，本地 P6 界面续做。遵循用户最新确认：不切换独立单场景，单场查看通过整体缩放实现；结果录入直接从场内发现，减少常规二维控件。没有创建、注册或部署 Site。

## 实现

- 三场地、候场区和人物保留在同一个世界。场地选择只请求正交镜头缩放，不再筛掉其他两场或把其他场地的选手移回候场。固定角度，支持双指／滚轮缩放、放大后空地平移、缩放按钮和全景复位。
- 记分牌具有场内立柱与牌框，牌面跟随实际世界坐标投影。按阶段显示“安排阵容 → 确认上场 → 录入赛果 → 继续录分 → 更正比分”，已完成直接显示有效比分。
- 点录分时镜头对准同一块牌，展开原生数字输入；没有独立场景或背景遮罩。输入期间锁住镜头与其他场内操作，关闭后回到原镜头。短屏牌内滚动、底部确认，visualViewport 变化时调整牌面位置。
- 上场确认仍核对完整四人；比分只在服务端接受后成为赛果。草稿、matchId、阵容／赛果版本、generation、冲突核对、幂等与保存反馈沿用原协议。只读者能看牌面，无比分输入和提交。
- 从更多菜单保留当前场次详情、误操作撤销、审计和名单更正；赛程／赛果仍按需打开。原始名单、赛程及业务规则没有改变。
