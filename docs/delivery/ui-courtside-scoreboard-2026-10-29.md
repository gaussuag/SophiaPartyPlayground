# 场边记分牌位置优化

2026-10-29，依据用户对“1 号场 · 等待赛果”的浏览器注释续做。原先两行或三行的牌子位于球场后沿，与场内人物和场地轮廓挤在一起。本次只调整场景呈现，沿用确认上场、录分、更正及权限协议，没有发布 Site。

## 设计与实现

- 常态牌面缩为单行，显示场号和当前操作；待排阵显示比赛类型，有赛果时直接显示比分和更正图标。完整场次与操作保留在可访问名称／提示及展开后的记分牌中。可见牌面 36px，按钮热区保留 44px。
- 桌面使用候场区后方的专用记分条带，避开比赛区域及人物；牌子、支架和 DOM 牌面仍绑定同一世界坐标。
- 竖屏把牌子留在场间空隙。按牌框的屏幕尺寸调整间距与全景取景，短屏相应调整比例；点场地后仍缩放同一个三场地世界，保留该场的操作入口。
- 大牌面仅在查看／录分时展开，关闭恢复原镜头。没有改变名单、赛程、身份、业务状态或共享保存方式。

## 验证

- 52 项自动检查通过。新增五种视口的投影检查：1385×892、1440×900、960×600、390×844、320×568；全景、三个场地的放大镜头以及最大缩放下，常态牌框均不与任何比赛区域重叠。全景与本场放大入口在检查的视口内。
- TypeScript 与本次文件 ESLint 通过，生产构建成功，输出 `outputs/courtside-build.log`。
- 浏览器实际检查桌面 1385×892、竖屏 390×844、短屏 320×568；三块场地保留，牌子与球场分开；放大、全景复位、查看赛果、操作员更正入口与输入继续可用。
- 浏览器验证使用独立 `local-scene-v3`；用户手机活动只做只读查看，没有提交或更改其赛果。
