# 人物移动与状态表现

基线：`06177a6`。实现于隔离分支 `codex/avatar-life`；本次仅改 venue 的人物呈现、Scene 人物装配与对应行为检查，不改 competition、records、session、HTTP 或持久化协议。集成后的浏览器截图与操作验收由整体游戏场景交付记录补充。

## 表现与操作

- 人物沿用稳定 `playerId`、黑白队服、肤色、发型与姓名；拆分双臂、双腿、头部，增加眼睛和比赛中的球拍。
- 每 14 秒播放一小段约 3 秒的错峰呼吸／观察动作，其余时间不请求帧；14 人有不同相位、方向与幅度。减少动态效果时跳过待机、选择短动作和赛果回应。
- 点选保持原有流程。可选 `Scene.pressedPlayerId` 提供不发业务意图的按下即亮圈；正式选择继续来自 `VenueProps.selection`。静态选中圈与本机短动作不会等待网络。
- 已安排有淡金位置圈，比赛中有青绿圈、持拍及更宽站姿，本轮已参赛有低亮金圈。当前轮完成后的选手回候场，历史轮仍在相应球场展示已确认阵容。
- 成功快照改变目的地后，人物先转向，再以步程驱动摆臂与步态，沿通道行走并到位站定。路径使用三个球场的外扩矩形、侧边出入口和少量角点；同场同半区可直接走，不穿过球网。没有物理引擎或新依赖。
- 目标中途改变时从当前可见坐标重算路线。人物根对象、模型热区和姓名锚点始终一起移动；根对象带稳定 `playerId`。镜头不被人物动画接管。

## 权威与恢复边界

`AvatarMotion` 只接收 Scene 从只读快照计算的目的地；没有保存、占位、开赛或结束回调。保存拒绝、冲突或结果未知没有新权威目的地，人物不会假装正式落位；待保存文字与错误反馈仍由 app/session 管理。更正名单的本机预览应由 app 保持与正式人物目的地分离。

`AvatarResults` 只消费当前轮从无有效赛果到已确认赛果的快照变化。获胜队短暂举手，另一侧点头回应。初次加载、刷新、WebGL 重建、查看历史、切回当前轮及恢复 generation 建立静默基线；轮询、比分更正和撤销后重录同场不重播。

切换轮次／世界布局／恢复 generation 时直接落到正确目的地。隐藏页面、重新可见或切换减少动态效果时取消尚未完成的表现并直接归位；重建场景从当前快照开始。动画结束只结束表现。

## 验证

`npx vitest run tests/venue/avatar-motion.test.ts tests/venue/avatar-results.test.ts`：11 项通过。

- 三种布局（390×844、390×600、1024×768），每种 26 个候场／席位点两两寻路，所有路线均未穿过三片球网。
- 先转向再移动、到位朝向；途中改目标不瞬移且仍避网；同目标轮询不重启；失败保存没有新目的地时不移动。
- 四人同时行走相互独立；减少动态效果、视图／generation 变化和恢复可直接归位。
- 只对新确认赛果回应；区分两队反馈；初始／重建静默；轮询、更正、历史切换、恢复与撤销重录不重播。

`npm run typecheck` 与改动文件 ESLint 检查通过。此记录不代表 Safari 真机、实际拾取或帧时序验收；完整场景的浏览器操作、截图和性能测量由集成阶段完成。

## 取舍

路径只绕固定球场／球网，不模拟人物之间碰撞；同时交换席位可以擦肩通过。步速固定为每秒 6.5 个场景单位，转向速度为每秒 11 弧度，以便长路径仍及时到位。角色不使用持续待机渲染；没有为了动画新增音效、震动或网络写入。

## 保存与动画联动补充检查

新增 `tests/venue/avatar-authority.test.ts`，通过 session 的真实公共接口、fake IndexedDB 和现有 transport 注入方式验证六种路径。测试使用真实 competition 决策与 AvatarMotion；小型 Scene 适配层只从 `SessionView.state` 投影席位坐标，不从待发命令或 pending envelope 设置人物目标。此检查覆盖模块边界，不代替浏览器中的 React 装配和实际触控。

1. 延迟保存回包期间状态为 `saving`、存在 pending，但正式位置仍在候场；接受新快照后只启动一次移动。
2. 422 拒绝保留原目标及位置，同时露出错误；不以动画冒充成功。
3. 409 冲突刷新新权威版本，不显示被拒绝的拟安排目标。
4. 服务端提交成功但响应丢失时先保持原位置；读取已确认快照后才移动，回执核对／再次刷新不会重启移动或再次 POST。
5. 请求未到达且没有回执时继续留在候场；只有显式使用原 commandId 重试并确认后才启动移动。
6. 确认替换同时驱动两个人物；中途确认回候场从可见位置改道，不使另一个已在移动的人物重启。

`npx vitest run tests/venue/avatar-authority.test.ts`：6 项通过；`npm run typecheck`、该文件 ESLint 与 `git diff --check` 通过。业务／同步源码没有修改。
