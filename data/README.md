# 活动模板

[event-template.json](event-template.json) 保存用户给出的完整名单、赛程与当前已确认规则。

- 它是模板，不是生产活动快照；运行时创建独立 eventId。
- 模板无任何预排阵容、确认记录或赛果。
- confirmedRules 来自用户明确确认；implementationDefaults 是方案默认值，不伪装为额外用户确认。
- deferred 保留原始数值含义和队伍总成绩算法等未定信息。
- event.date 与 event.timeZone 留空，防止把开发日期或设备时区当作活动事实。
- warmup 与 courtBlocks 不属于正式 matches；第七轮只有两场。
- 姓名、性别和数值按原名单保留；不能依据姓名或角色模型猜测性别。
- ID 的活动内唯一性在初始化与导入时验证，跨活动引用加 eventId。
- 任何种子加载必须显式、幂等，并拒绝覆盖已经存在的正式活动。
- 源码只保留模板和受控测试数据，真实活动导出及本地数据库放在忽略目录。

核对基准：14 人、每队 7 人且各 4 男 3 女；3 场地；7 轮；20 场；混双 7、女双 1、男双 2、男单 3、女单 1、自由双打 6；共 72 人次。
